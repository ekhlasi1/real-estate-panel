## ✨ ویژگی‌ها

| ویژگی | توضیح |
|-------|--------|
| 🏢 **مدیریت ملک‌ها** | افزودن، ویرایش، حذف و تغییر وضعیت ملک‌ها |
| 👥 **مدیریت مشاورین** | افزودن و حذف مشاورین با حساب کاربری |
| 📊 **داشبورد اختصاصی** | آمار لحظه‌ای برای هر مشاور |
| 🏷️ **نمایش وضعیت** | موجود / فروش رفته / اجاره رفته روی تصویر |
| 📱 **ریسپانسیو کامل** | سازگار با موبایل، تبلت و دسکتاپ |
| 🎨 **تم طلایی-مشکی** | طراحی حرفه‌ای و شیک |
| 📸 **آپلود فایل** | تصاویر و ویدئو (بدون نیاز به R2) |
| 📝 **دفترچه یادداشت** | یادداشت‌های شخصی برای هر کاربر |
| 📇 **لیست مخاطبین** | مخاطبین مشترک بین همه کاربران |
| 🤝 **درخواست کارشناسی** | فرم درخواست برای بازدیدکنندگان |
| 📞 **نمایش شماره مشاور** | نمایش شماره تماس مشاور روی هر آگهی |
| 💾 **بکاپ خودکار** | هر روز ساعت ۲۴:۰۰ به‌صورت خودکار |
| 🔄 **بازگردانی اطلاعات** | آپلود فایل بکاپ و بازیابی کامل |
| 📊 **گزارشات** | گزارش فروش و عملکرد مشاورین |
| 🚀 **اجرا روی Cloudflare** | بدون نیاز به سرور اختصاصی |
